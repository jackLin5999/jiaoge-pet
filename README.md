# 小 Claude 桌宠

一只用 Swift + AppKit 写的 macOS 桌面宠物，形象参考 Claude 的像素 logo：橙色方块身体、两只方形眼睛、四条小短腿。

## 运行

```bash
./run.sh        # 编译并启动
./build.sh      # 只编译，产物在 build/ClaudePet.app
```

启动后没有 Dock 图标，菜单栏会多一个 🟠。

## 交互

| 操作 | 反应 |
|---|---|
| 左键单击 | 压扁回弹、挥手、冒爱心、说一句话 |
| 连续点击 | 显示「连击 ×N」；4 下开始瞪大眼，7 下变成 ×× 眼并摇头，台词也逐级升级 |
| 按住拖动 | 拎起来（身体拉长、眼睛睁大），松手后停在放下的位置 |
| 右键 | 菜单：说句话 / 跳一下 / 大小 / 回到默认位置 / 退出 |
| 菜单栏 🟠 | 同样的菜单 |

连击计数在停手 2.2 秒后自动归零。大小分 小 / 中 / 大 / 超大 四档，选完会记住，下次启动沿用。

## 闲置时的小动作

即使不碰它，也会：

- 一直有呼吸起伏（约 0.3 秒一次）
- 每 2–5 秒眨一次眼
- 每 7–15 秒随机做一个动作：原地跳一下、左右看看、伸个懒腰扭一扭
- 鼠标不在它身上时，窗口自动点击穿透，不会挡住后面的操作

## 改起来方便的地方

都在 `Sources/main.swift` 顶部：

- `CELL`：整体缩放（现在是 4，改 5 就变大）
- `claudeOrange`：主体颜色（现在取的是参考图里的 `#CC7C5E`）
- `PetController.lines`：点击时随机说的台词
- `makePose()`：所有动画曲线，想加动作在这里加
- `hitAreaContains`：可点击区域
