# 蕉哥

> 平台：**仅支持 macOS 12+**（Apple Silicon；Intel 需要自行编译通用二进制）。Windows / Linux 无法运行。

蕉哥是一只 macOS 桌面宠物：一根会呼吸、会眨眼、会挥手的香蕉。
用 Swift + AppKit 写成，造型照着 `docs/banana-reference.png` 画，全部用 Core Graphics 现画，没有图片素材。

## 运行

```bash
./run.sh        # 编译并启动
./build.sh      # 只编译，产物在 build/JiaoGe.app
```

启动后没有 Dock 图标，菜单栏会多一个 🍌。

## 交互

| 操作 | 反应 |
|---|---|
| 左键单击 | 压扁回弹、挥手、冒爱心、说一句话；**戳不同部位说的话不一样**（头顶／眼睛／嘴／手／脚／肚子各有台词，戳眼睛还会闭一下眼） |
| 连续点击 | 显示「连击 ×N」；4 下开始瞪大眼，7 下变成 ×× 眼并摇头，台词也逐级升级 |
| 按住拖动 | 拎起来（身体拉长、睁大眼），松手后停在放下的位置 |
| 右键 | 打开 / 关闭剪贴板面板（再点一次就收起） |
| 菜单栏 🍌 | 完整菜单，番茄钟运行时这里会显示倒计时 |

连击计数在停手 2.2 秒后自动归零。大小分 小 / 中 / 大 / 超大 四档，选完会记住，下次启动沿用。

## 聊天

菜单里的「打开对话框」会在头顶弹出一个输入框，打完字回车发送，回复显示在气泡里（支持多行）。
Esc 收起（右键宠物留给剪贴板了）。

第一次用要先在「大模型设置…」里选服务、填 API Key，也可以点「测试连接」确认通不通。
接口走 OpenAI 的 `/chat/completions` 格式，所以下面这些都行：

| 服务 | API 地址 | 模型示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V3` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| Ollama（本地） | `http://localhost:11434/v1` | `qwen2.5` |

其他兼容 OpenAI 格式的服务选「自定义」填就行。配置和 Key 存在
`~/Library/Application Support/JiaoGe/config.json`，文件权限 600，只有本机这个账号能读。

聊天记录只保存在内存里，重启就没了；最近的 12 条会作为上下文一起发出去。

## 截图识字 / 截图翻译

- **⌃⌥O**：框选屏幕区域（系统自带的选框，Esc 取消），本地识别文字，结果直接进剪贴板，也会留在剪贴板历史里。
- **⌃⌥T**：同样框选，识别后交给大模型翻译（原文是中文就翻成英文，否则翻成中文），译文进剪贴板并显示在气泡里。

识别用的是系统的 Vision 框架，**本地跑、不联网**；只有翻译那一步会调接口，所以要先把大模型配好。

**两种翻译模式**：

| 模式 | 原理 | 适合 |
|---|---|---|
| 本地识别 + 文本翻译（默认） | Vision 在本机把图转成文字，再把文字发给模型 | 文本模型也能用；不联网识别、省钱、快 |
| 直接发图（需多模态模型） | 整张截图发给模型，由模型自己读字并翻译 | 表格、复杂排版、手写更准；更贵更慢，图片会离开本机 |

在「大模型设置」里勾选「这个模型能看图」就切到第二种。DeepSeek 的话模型要填 `deepseek-flash`
（`deepseek-chat` 是纯文本的旧 ID，发图会报 400）。

没配置大模型时，「截图翻译」那一项会直接标上「需先连接大模型」；按 ⌃⌥T 会先提示再自动帮你打开设置。

翻译结果的**气泡会一直停在屏幕上**，直到你在任何地方点一下鼠标才收起——方便慢慢看、对照原文。

**目标语言**：菜单里的「翻译目标语言」子菜单（就在「截图翻译」下面）。默认「自动」＝原文是中文就翻英文、
否则翻中文；也可以固定成中文／英文／日文／韩文／法文／德文／西班牙文／俄文，两种翻译模式都会遵守。

**语种**：实测能识别中、日、韩、英、法、德、西、葡、越南、俄、阿拉伯、泰、印地。

Vision 对"指定语言列表"非常敏感——列表里混入中文，韩文就会被认成汉字、西里尔字母会失效，
语言一多整体精度也会掉。所以现在按文字类型**分轮识别**：中日英 → 韩 → 阿拉伯 → 泰 → 印地 → 自动，
**第一轮达标（字数够、置信度 ≥ 0.7）就直接返回**，常见情况只跑一次（70–300ms）；
其它语种才依次多跑几轮，通常 0.5 秒内出结果。

少数拉丁字母语言的变音符号会丢（比如西语的 ñ、越南语的声调），但文字本身是对的，不影响翻译。

识别后会按文字框的坐标把排版拼回去：

- 同一行的多块文字用 `  |  ` 隔开，所以**表格会变成一行行表格数据**
- 检测到左右分栏时，**按栏读**（先读完左栏再读右栏），不会左右串行
- 行距大的地方留空行，保留段落

翻译长内容时会**按行分段**逐段请求再拼起来；某段如果被长度上限截断（`finish_reason == length`），
会自动对半拆开重试，所以再长的截图也不会被截掉尾巴。

第一次用如果提示截不到图，去「系统设置 → 隐私与安全性 → 屏幕录制」里给蕉哥打钩。

## 每日小结

晚上 **21:30** 它会说一段今天的总结，比如：

> 今天被戳了 42 次，专注 3 个番茄共 75 分钟，复制了 12 段内容，跟我聊了 5 次。辛苦啦，早点休息

没有活动就不打扰。菜单里的「看看今天的小结」可以随时手动看一次。

## 音效

点击「叮」、升级一段和弦、番茄结束「咚」、聊天收到回复「啵」。菜单里的「音效」可以随时关掉。

## 聊天记忆

聊天记录会存到 `~/Library/Application Support/JiaoGe/chat.json`，重启后接着聊（保留最近 50 条）。
菜单里的「清空聊天记忆」可以清空。

## 番茄钟

菜单「番茄钟」→「开始专注」，剩余时间会显示在菜单栏（🍌 24:59）。专注结束会自动进入休息，
休息结束会提醒一次。默认 25 分钟专注 / 5 分钟休息，可以在菜单里改成 15 / 25 / 50 和 5 / 10。

## 久坐提醒

菜单「久坐提醒」，默认每 45 分钟提醒一次（它会伸懒腰并说一句话），可以改成 30 / 60 分钟或关掉。
这个计时从启动或上次提醒开始算，不会检测你实际有没有在动。

## 剪贴板历史

后台每 0.5 秒看一次剪贴板，**文字和图片**都记，最近 20 条。

- **右键宠物**，或任何 app 里按 **⌃⌥V**：宠物头顶弹出最近的 10 条，数字键 1–9 直选，↑↓ 加回车也行，Esc 或点面板外面的任意地方都会关掉。
  选完自动放回剪贴板，并把你切回原来的 app，接着按 ⌘V 就行。
  没用 ⌥⌘V 是因为它在不少编辑器里是「粘贴并匹配样式」。
- 菜单栏 🍌 的菜单最上面直接列最近 5 条，点一下就复制。
- 面板顶部有搜索框，输入即筛选（搜索覆盖全部 20 条，面板最多显示 10 行）
- 点每行右边的 📌 可以置顶，置顶的条目不会被挤出历史
- 菜单「剪贴板」里有完整列表、「记录剪贴板」开关和「清空历史」。

图片（截图、网页里复制的图、在访达里复制的图片文件）会存成 PNG，面板里显示缩略图和尺寸，
选中就把它放回剪贴板。图片按内容哈希命名，重复的图不会存两份；超过 40MB 的不记。
条目被挤出历史或清空时，对应的图片文件会一起删掉。

看起来像密钥的单行 token（`sk-`、`AKIA`、`ghp_` 这类前缀）不会被记录。
历史存在 `~/Library/Application Support/JiaoGe/clipboard.json`，图片在同目录的 `clip/` 下，
都只有本机这个账号能读。

## 统计与好感度

菜单里会显示：

- 「今天被戳了 N 次」，每天零点自动归零
- 「今天专注 N 个番茄 · M 分钟」
- 「好感度 Lv.N 段位 · X/Y · 连续 K 天 · 认识第 D 天」（点一下它会冒爱心说出来）

**经验来源**：点击 +1、聊天成功 +5、完成番茄 +20，**没有每日上限**；
每天第一次互动额外 +10 起（连续天数越多越多，封顶 +50）。

**段位**参考英雄联盟：黑铁 / 黄铜 / 青铜 / 白银 / 黄金 / 铂金 / 翡翠 / 钻石 各分 IV–I（共 32 级）。
升到 Lv.33 进入**大师**，之后不再看等级，改看分数——**每 2 点经验 = 1 分**：

| 分数 | 段位 |
|---|---|
| 0 – 799 | 大师 |
| 800 – 1199 | 宗师 |
| 1200 – 1999 | 王者 |
| 2000 以上 | 神（隐藏段位） |

每级需要 13、26、39…… 经验。按每天 150 经验算：白银约第 7 天、翡翠约第 26 天、
大师约第 46 天、宗师约第 56 天、王者约第 62 天（两个月出头）、神约第 72 天，
之后继续按分数累积，没有上限。

5、10、20、30 级各有一句专属台词，大师之后每次换段位也会说一句。

**皇冠**：每个段位都有自己的皇冠，**连四个小段都不一样**（宝石点亮数量递增，IV 最少、I 最多），
所以每升一级头上那顶都会变。素材在 `Resources/crowns/`（`<大段位>_<1-4>.png`，1=IV、4=I），
大师以上是单张。预览见 `docs/crowns-on-pet.png`。

> 素材来自几张设计稿：黑铁～白银一张、黄金～钻石一张（都是每级宝石逐级点亮）。

## 按时间与主动提醒

- **打招呼**：启动时按时间说早/午/晚/晚安
- **深夜**（22 点后）它会更容易打瞌睡
- **午饭**：12 点提醒一次
- **喝水**：9–21 点每小时提醒一次
- **连续用电脑 90 分钟**：劝你起来动一动（根据键鼠闲置时间判断）
- **电量低于 20%**：提醒充电（充满后重新计数）
- **CPU 长时间跑满**（>85% 连续 30 秒）：它会抖一抖说「好热」
- **网络断开/恢复**：会说一句

## 开机自启

菜单里的「开机自动启动」，勾上以后开机自动出现（用系统的 `SMAppService`，需要 macOS 13+）。

## 闲置时的小动作

即使不碰它，也会：

- 一直有呼吸起伏（约 0.3 秒一次）
- 每 2–5 秒眨一次眼
- 每 6–13 秒随机做一个动作：原地跳一下、左右看看、伸个懒腰扭一扭、
  打个哈欠、歪着头卖萌、抖一抖、打瞌睡（偶尔还会说「哈啊～」「zZ…」）
- 闲着的时候眼睛会跟着鼠标转
- 鼠标不在它身上时，窗口自动点击穿透，不会挡住后面的操作

## 改造型

造型是直接按参考图的像素坐标画的：`Banana` 里每个部件的点都写成参考图（560×750）上的坐标，
画的时候用 `artToView` 统一缩放，所以改大小只要动 `CELL`，几何数字不用重算。

- `Banana.body` / `stem` / `leftArm` / `rightArm` / `feet` / `spots`：各部件轮廓
- `rgb(...)`：配色全部取自参考图，**按 Display P3 标注**——参考图就是 P3 色彩空间，
  写成 sRGB 会明显偏淡
- `PetController.lines`：点击时随机说的台词
- `makePose()`：所有动画曲线（呼吸、眨眼、跳、挥手、压扁、拖拽），想加动作在这里加
- `hitAreaContains`：可点击区域（现在是身体、果柄、手臂、脚各放宽一圈）

## 发布到 GitHub

```bash
./release.sh      # 产出 build/JiaoGe-0.1.0.zip
```

两种分发方式，建议一起提供：

**1. Releases 里放预编译包（普通用户，不需要命令行工具）**

`./release.sh` 生成的 zip 里包含 `JiaoGe.app` 和一份 `安装说明.txt`，用户解压后照着做即可。
完整版说明见 [INSTALL.md](INSTALL.md)。

用户下载 zip → 解压 → 拖进「应用程序」。第一次打开会被 Gatekeeper 拦（因为没做公证），
告诉用户任选一种放行：

- 右键点 app → **打开** → 再点一次「打开」
- 或 系统设置 → 隐私与安全性 → 底部「仍要打开」
- 或命令行：`xattr -dr com.apple.quarantine /Applications/JiaoGe.app`

放行后还有两件事：**第一次截图会请求屏幕录制权限**（允许后要重启 app），
以及**自己在大模型设置里填 API Key**。

**2. 源码（开发者）**

需要 Command Line Tools（`xcode-select --install`），然后 `./build.sh`。

**关于架构**：`ARCHS=universal ./build.sh` 会尝试编 arm64 + x86_64 的通用包，
但命令行工具里没有 x86_64 的 Swift 兼容库，**必须装完整 Xcode** 才能成功；
否则会自动退回本机架构（当前是 arm64，Intel Mac 用不了）。

**想彻底免掉 Gatekeeper 这一关**：需要 Apple Developer Program（99 美元/年）做 Developer ID 签名 + 公证。

## 文件

- `Sources/main.swift`：造型、绘制、动画、气泡、控制器
- `Sources/Features.swift`：大模型配置与请求、聊天输入框、设置窗口

## 说明

- 用 Command Line Tools 的 `swiftc` 直接编译，不需要装 Xcode
- 本机 ad-hoc 签名，只适合自己用；要分发给别人需要正式签名和公证
- API Key 没有放进钥匙串：这个 app 是 ad-hoc 签名的，每次重新编译签名都会变，
  钥匙串会反复弹授权框。所以改存 `~/Library/Application Support/JiaoGe/config.json`，
  文件权限 600，只有本机这个账号能读
- 命令行里也能问一句，方便排查：`JIAOGE_API_URL=… JIAOGE_API_KEY=… ./build/JiaoGe.app/Contents/MacOS/JiaoGe --ask "你好"`
