一只会呼吸、会眨眼、会挥手的桌面香蕉宠物，顺手还能干点正事。

## 能做什么

- **📷 截图识字** `⌃⌥O` —— 框选屏幕直接出文字。13 种语言，本地识别不联网，表格和多栏排版能还原
- **🌐 截图翻译** `⌃⌥T` —— 框选直接出译文。长文自动分段、截断自动重试，译文常驻屏幕，点别处才收起
- **📋 剪贴板记忆** `⌃⌥V` —— 文字、图片都记得住，能搜索、能置顶，选一条直接放回剪贴板
- **💬 大模型聊天** —— 接 DeepSeek / 通义 / Kimi / 智谱 / OpenAI / 本地 Ollama，记录重启后还在
- **🍅 番茄钟 + 久坐提醒** —— 菜单栏倒计时，坐太久、该喝水、电量低了都会开口
- **🏆 段位养成** —— 黑铁打到王者，头顶皇冠随段位更换

## 安装

> ⚠️ **本包只支持 Apple Silicon（M 系列芯片）的 Mac，macOS 12 以上。Intel Mac 无法运行。**
> Intel 用户需要自行安装完整 Xcode，用 `ARCHS=universal ./build.sh` 编译。

1. 下载 `JiaoGe-1.0.2.zip`，解压
2. 把 **JiaoGe.app** 拖进「应用程序」
3. 第一次打开会被拦下，提示「Apple 无法验证…」——这是正常的（没做 Apple 公证），不代表有问题。
   点「完成」后去 **系统设置 → 隐私与安全性**，往下滚点「**仍要打开**」，验证指纹后再双击 app。
   或者命令行一步搞定：`xattr -dr com.apple.quarantine /Applications/JiaoGe.app`
4. 第一次按 ⌃⌥O 会请求「屏幕录制」权限，**允许后要把 app 退出再打开**才生效

## 首次配置

菜单栏 🍌 →「大模型设置…」，填 API 地址 / 模型 / Key。

DeepSeek 填 `https://api.deepseek.com/v1`，模型 `deepseek-flash`（支持看图，聊天也能用）。
**截图识字不需要配置**，只有翻译和聊天需要。

## 1.0.2 改了什么

- **加了一个不依赖菜单栏的入口**：按住 **⌥ 右键**点宠物，就能弹出完整菜单（含「大模型设置…」）。
  有些 Mac 菜单栏太挤会把图标藏起来，之前会导致完全打不开设置
- 启动时会检查菜单栏图标是否真的显示出来了，没显示会主动提示备用操作
- 「自检」命令会报告菜单栏图标状态
- 没配置模型时，第一次启动的提示也带上了这个备用入口

## 1.0.1 修复了什么

- **修掉一个严重问题**：1.0.0 的二进制把最低系统版本写成了 macOS 27（编译机的系统），
  导致 macOS 14 及更早的系统打开时会提示「这个版本不能与此版本的 macOS 配合使用」。
  现在的最低系统版本是 **macOS 12.0**，和我声明的一致

## 已知限制

- 仅提供 Apple Silicon 构建；未签名公证，首次打开需要手动放行一次
- 西语、越南语等拉丁字母语言的变音符号在识别时可能丢失（不影响翻译理解）
- 需要 macOS 12 以上，开机自启需要 13 以上
