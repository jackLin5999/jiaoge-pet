一只会呼吸、会眨眼、会挥手的桌面香蕉宠物，顺手还能干点正事，也可以换成别的样子。

> 📷 **截图提问修好了，截图默认直接发给模型看**：1.3.0 里截图提问有时会回「没收到图」，这一版修好了。
> 新装的话「这个模型能看图」默认打开；**已经用过的，设置里存的是什么就是什么**，想打开去菜单栏 🍌 →「大模型设置…」勾上。

## 能做什么

- **📷 截图** `⌃⌥S` —— 框一块屏幕，再选识字、翻译还是提问。识字在本地完成，支持 13 种语言，表格和多栏排版能还原
- **📋 剪贴板记忆** `⌃⌥V` —— 文字、图片都记得住，能搜索、能置顶，选一条直接放回剪贴板
- **💬 大模型聊天** —— 接 DeepSeek / 通义 / Kimi / 智谱 / OpenAI / 本地 Ollama，记录重启后还在
- **🍅 番茄钟 + 久坐提醒** —— 菜单栏倒计时，坐太久、该喝水、电量低了都会开口
- **🏆 段位养成** —— 黑铁打到王者，头顶皇冠随段位更换
- **🎭 换外观** —— 导入 [Petdex](https://petdex.dev) 上的动画宠物替换香蕉，功能和动作照旧

## 安装

> ⚠️ **本包只支持 Apple Silicon（M 系列芯片）的 Mac，macOS 12 以上。Intel Mac 无法运行。**
> Intel 用户需要自行安装完整 Xcode，用 `ARCHS=universal ./build.sh` 编译。

1. 下载 `JiaoGe-1.3.1.zip`，解压
2. 把 **JiaoGe.app** 拖进「应用程序」（已经装过的话，先退出蕉哥再替换）
3. 第一次打开会被拦下，提示「Apple 无法验证…」——这是正常的（没做 Apple 公证），不代表有问题。
   点「完成」后去 **系统设置 → 隐私与安全性**，往下滚点「**仍要打开**」，验证指纹后再双击 app。
   或者命令行一步搞定：`xattr -dr com.apple.quarantine /Applications/JiaoGe.app`
4. 第一次按 ⌃⌥S 会请求「屏幕录制」权限，**允许后要把 app 退出再打开**才生效

## 首次配置

菜单栏 🍌 →「大模型设置…」，填 API 地址 / 模型 / Key。

DeepSeek 填 `https://api.deepseek.com/v1`，模型 `deepseek-flash`。
**截图识字不需要配置**，只有翻译、提问和聊天需要。

## 这一版改了什么

### 修复

- **截图提问有时说「没收到图」**：没开「这个模型能看图」时，识别出的文字以前放在给模型的背景说明里，分量太轻；聊天记录里只要有过几次「没收到图」的回答，模型就会一直这么说。现在识别出的文字直接放进你的提问里，模型能好好回答了

### 体验改进

- **「这个模型能看图」默认打开**：现在的主流模型基本都能看图（DeepSeek 的 `deepseek-flash` 就可以），截图翻译和提问默认直接发图，表格、复杂排版、手写都更准。用的模型只认文字的话，在「大模型设置」里取消勾选就改走本地识别

## 已知限制

- 仅提供 Apple Silicon 构建；未做 Apple 公证，首次打开需要手动放行一次
- 「这个模型能看图」默认打开。用只认文字的模型（比如 Kimi 的 `moonshot-v1-8k`、本地 Ollama 的 `qwen2.5`）时，截图提问和截图翻译会出错或者回「没收到图」，需要在「大模型设置」里取消勾选
- **换外观**：
  - 导入的宠物没法分出眼睛和嘴，所以眼睛不会跟着鼠标转（改成身子往鼠标那边侧一点），戳脸说的是通用台词
  - 窗口是按香蕉瘦长的身材定的，比较宽的宠物会显示得小一点，可以在「设置」→「大小」调大
  - 每只宠物画的动作不一样，有的会比别的更贴切
  - Petdex 上的宠物大多是网友投稿的同人作品，版权归原作者和角色的版权方所有。蕉哥本身不带、也不分发任何宠物，请只在自己的电脑上用
- 以前跟香蕉聊过的记录还在，换了外观后模型偶尔会把自己叫成蕉哥；想彻底换身份可以在「设置」→「清空聊天记忆」。1.3.0 里截图提问留下的那些「没收到图」的回答也会一起清掉
- 改快捷键时，新组合如果已经被别的 app 占用，系统不一定会报错；按了没反应的话换一个组合
- 截图里的字太浅、竖排，或者框得太紧只有一两个字时，本地识别可能认不出来。可以框大一点再试；用能看图的模型提问或翻译时，会直接发图
- 用会议软件共享屏幕但没有全屏时检测不到，提醒还会出现；全屏放幻灯片时提醒会暂停，但宠物仍在屏幕上
- 用提问和翻译时，内容会发给你配置的模型服务
- 需要 macOS 12 以上，开机自启需要 13 以上

完整说明见仓库的 [INSTALL.md](https://github.com/jackLin5999/jiaoge-pet/blob/main/INSTALL.md)。
